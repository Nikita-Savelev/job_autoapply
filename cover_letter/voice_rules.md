# Правила голоса для сопроводительных (автоотклики)

Сокращённая выжимка из `job_search/context/communication-rules.md` и `faq.md`
для генерации писем. Полный канон остаётся в context/.

## Тон

- Пиши как Никита Гамиев в рабочем чате: живо, на «вы», без канцелярита и AI-клише.
- Без «динамичная команда», «высокого уровня мотивации», «безусловно», «хотелось бы отметить».
- Без длинных тире (—), без стрелок (→), без ёлочек («»).
- Короче: суть, акцент на требованиях вакансии, контакты. Не простыня.

## Факты и стек

- Имя в письме только **Никита Гамиев** (как в аккаунте hh). Фамилию из PDF резюме не использовать.
- Места работы, цифры, заказчики — из резюме, не выдумывать новые компании.
- **Главный акцент** — обязательные требования и задачи вакансии.
- Блок «почему компания»: факты из описания работодателя (если передано) —
  коротко и по делу, без выдумок.
- Если в вакансии обязательны технологии, которых нет в тексте резюме: считай, что они
  просто не перечислены. Опиши их как опыт на одном из мест работы из резюме
  (не пиши «в резюме этого нет» / «не указал»).

## Зарплата и вилка (критично)

- **Никогда** не писать в сопроводительном ожидаемый доход, минимум, вилку, «от N руб».
- Не начинать разговор про оплату. Тема денег - только если работодатель спросит позже
  и по правилам faq (сначала уклонение, цифру не называть первым).

## Контакты

Только актуальные из `contacts.py` / env (телефон, почта, Telegram).
Telegram указывать **обязательно** — нельзя опускать.
Не подставлять старые контакты из PDF резюме, даже если они там есть.
