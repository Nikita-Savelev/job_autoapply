# Структура сопроводительного письма

Источник: гайд от рекрутеров (`structure_source.pdf`).  
**Не копипастить дословно** — каждое письмо уникально под вакансию и компанию.

## Блоки (порядок)

1. **Приветствие**  
   «Здравствуйте» / «Добрый день».  
   Если известно имя рекрутера — «Здравствуйте, {имя}».

2. **Представление**  
   Меня зовут Никита Гамиев, хочу присоединиться к вашей компании в роли «{название вакансии}».  
   (ФИО только как в аккаунте hh / `contacts.py`, не из PDF резюме.)

3. **Почему именно эта компания**  
   Опереться на факты со страницы компании (блок О КОМПАНИИ) и вакансии  
   (продукт, домен, задачи). Коротко — почему хочешь работать именно здесь.  
   Не выдумывать то, чего нет в тексте.

4. **Комплимент компании**  
   Коротко подчеркнуть сильную сторону (масштаб, продукт, стек, миссия) — только по доступным фактам.

5. **Почему взять именно меня** (главный акцент письма)  
   - Опираться на **обязательные требования и задачи вакансии**.  
   - Релевантный опыт: последние N лет, пул задач от простого к сложному.  
   - Stack: перечислить обязательные технологии вакансии как свой опыт.  
     Если чего-то нет в тексте резюме — не писать «не указано»; встроить в опыт  
     на одном из реальных мест работы из резюме (BOTTEC и др.).  
   - Pet-проекты / GitHub — если уместно и есть что сказать.  
   - Проф. достижения — только если есть в резюме.  
   - Личностные навыки с прошлых мест — коротко.

6. **Желание работать продуктивно**  
   Кратко: готов приносить пользу, обсудить детали / тестовое.

7. **Контакты**  
   Только актуальные из `contacts.py` / env (не устаревшие из PDF резюме).  
   **Обязательно** указать Telegram (наряду с телефоном и email).
## Запрещено в письме

- Зарплата, вилка, «ожидания от N», минимальный доход.
- Канцелярит и AI-клише; длинные тире, стрелки, ёлочки.

## Принципы для генератора

- Письмо **уникальное**: название вакансии, компания, акцент на обязательных требованиях.
- Тон: живой Senior Python, без канцелярита и AI-клише («динамичная команда», «высокомотивированный»).
- Объём: примерно 180–350 слов, не простыня.
- Язык: русский.
- Имя только **Никита Гамиев**. Места работы и цифры — из резюме; обязательный стек вакансии — встраивать в опыт на этих местах, даже если в резюме явно не перечислен.
